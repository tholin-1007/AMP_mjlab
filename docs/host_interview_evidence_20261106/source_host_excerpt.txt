   MY IMPLEMENTATION  把“起身策略”， 变成“受困恢复策略”。  单个学生策略持续学习，固定教师只提供训练参考，回放时不切换到教师控制。     01   适配身体：不只是多六个输出  对齐 29 轴观测、动作、惯量与限位，为腰腕配置对应力矩限制；通过逐关节站姿目标与上肢残差分支，修复腰腕贴限位。     02   改变目标：先移动，再站起来  降低板下正向起身信号，奖励躯干向出口刷新进展、手撑推动与手臂抽离。连续无接触与净空确认后，重新强调起身。     03   保留旧技能，同时学习新接触  平地教师约束起身与站姿；受困教师仅指导其覆盖的导向板俯卧/仰卧。扩展 reset 配额后，继续检查各姿态表现与平地能力回退。

   OBSERVED FAILURE / 改进前的问题  腿蜷起来了，身体却还在板下。   奖励与 critic 适配前
 仰卧与俯卧初态都出现过蜷腿受困：腿部明显屈曲，躯干仍处在压板覆盖范围内。下面两张失败回放截图，是我们进一步调整腿部奖励、并用 target critic 承接脱困目标的直接问题背景。

      01 / 仰卧起点  屈膝收腿，躯干仍被覆盖  腿部收拢没有带来有效的全身移出，恢复动作仍受到上方压板限制。
      02 / 俯卧起点  双腿折叠，未形成有效脱困  身体改变了姿态，但仍未摆脱板的覆盖，说明仅有动作变化不足以完成恢复。

  由失败现象落到两个改动   腿部奖励： 约束过度蜷缩，让释放与躯干位移协同。  critic 适配： 复用 target 组学习脱困目标，分阶段平衡起身与移出信号。  截图用于呈现具体失败现象；单项改动的收益仍需独立消融评估。


  HoST / 腿部奖励适配  让腿跟着身体脱困， 而不只是蜷起来、让覆盖看起来变少。  在共享几何进展奖励之上，加入 屈膝代价、伸腿引导与腿部释放门控 。重点处理上下导向板场景：让有效移动来自躯干向外推进，并在确认离板后把活动自由度交还给起身动作。

  01 / 抑制蜷缩取巧
  俯视示意：机器人躯干仍在板下，双腿蜷缩，几何覆盖减少不代表有效脱困   压板投影         身体没移出 · 收腿不等于脱困
 深屈膝、深屈髋付出代价  双膝偏离参考姿态过多时持续扣分；上下板额外抑制膝、髋深弯，并保留直腿引导，避免只靠蜷缩身体获取几何收益。  两类板：离板前膝惩罚
  02 / 奖励协同移出
  俯视示意：躯干向板外移动，双腿较直；腿部释放奖励同时检查躯干位移与腿姿   压板投影         躯干向外推进 + 较直腿姿
 伸腿与位移共同满足条件  奖励伸展与腿部释放；释放项必须同时有躯干位移和较直腿姿。几何进展还受腿姿与抬板安全门控，减少原地蹬腿或顶板获益。  上下板：位移 × 腿姿门控
  03 / 离板后切回起身
  阶段切换示意：确认离板后关闭离板前双膝蜷缩惩罚，允许为起身重新屈膝          恢复目标重新强调起身与站立
 解除受困阶段的膝部约束  首次确认离板后，双膝蜷缩惩罚锁存关闭，避免伸腿要求妨碍正常起身。随后恢复起身任务；上下板俯卧分支另加入高度与直立进展。  阶段切换：从移出到恢复

 前两幅为俯视几何示意，第三幅为起身阶段示意，均非真实轨迹。腿部释放不等于全身脱困，手臂等部位仍需通过离板检查。

  关键设计 / 目标冲突的化解  给脱困目标独立的价值估计， 让“先移出、再起身”参与同一次策略更新。  板下直接追求身体抬高，容易变成顶板、蜷腿和卡滞。我们 复用 HoST 已有的第四个 target critic ：将原本偏向站起后稳定状态的奖励组，扩展为受困阶段的脱困反馈，并按离板状态调整训练重点。

  真正需要适配的地方：优势归一化之后，还要调权。  HoST 四组优势分别归一化，直接缩小原始 reward 的量级可能被抵消。因此受困阶段还将 task / style 的 归一化后优势乘 0.05 ，保留 target 脱困信号和 regu 成本信号，再合成 PPO 更新。
 本项目 AMP 将任务与风格奖励混合后训练，未为脱困新增独立 critic；HoST 则复用已有的多 critic 结构进行目标分工。这是针对任务冲突的奖励与优势适配设计；尚无单独消融量化 target 组改造本身的收益。

  技术细节：腿部奖励的参数与作用范围
  双膝蜷缩惩罚 · 两类板  参考膝角 0.30 rad，容许偏差 0.30 rad（约 17.2°）。令超量 e = max(0, |q膝 − 0.30| − 0.30)，每侧代价为 e / (e + 0.25) + 0.20e，左右相加后取负，系数为 −1.00。  容许带决定何时开始扣分；饱和项使初期超量有明显反馈，线性项让深弯时仍保留惩罚梯度。这是软奖励，不是把膝关节锁死在某个角度。
  伸腿与释放 · 上下板  膝/髋深弯项系数为 −0.90 / −0.35 / −1.20；另有 +0.80 的线性直腿信号。伸腿与释放相关项为 +0.50 / +0.25 / +0.12 / +0.80，并乘对应阶段权重。  释放项检查躯干位移与较直腿姿；基础几何进展也经过腿姿和抬板安全门控。目标是协同移出，而非独立奖励脚部摆动。
  上述为机制对照记录中的奖励率系数，实际每控制步还乘 dt = 0.02 s，再经 target critic 的优势计算与归一化；系数大小不能直接当作 PPO 梯度大小。膝部改动与课程、教师约束、动作先验等共同作用，单项收益需消融验证。
  HoST 的 style 是其运动约束奖励组，不是 AMP 对抗判别器。HoST 本项目 actor 使用板特征，AMP actor 不使用；两者信息条件需要在后续对比中明确控制。
  为什么 HoST 不能直接复制 AMP 的奖励系数？   HoST 的四个 critic 分别计算并标准化优势。仅缩小原始 reward，缩放可能在归一化后被抵消。因此受困阶段还需要调整 task / style 的归一化优势倍率，让 target 组的脱困信号有效参与策略更新。  导向板未离板时关闭选定正向起身分量；两类板下 task / style 优势缩至 0.05。动作代价与安全项仍有效。固定教师增加软约束，但学生 actor 与 critic 仍由 PPO 持续更新。  离板确认需要曾与板接触、当前无接触并连续 25 步满足净空；导向板水平净空 ≥4 cm，自由板几何净空 ≥2.5 cm。导向板强调水平离开，避免把竖直顶板视为脱困。
